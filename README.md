
# Isometric Projection Engine

A C++-based 2D isometric projection engine developed using **SFML**, designed to provide the foundational systems required for building an isometric game.

## Features

* 2D-to-isometric coordinate projection
* Isometric tile/grid rendering
* Camera movement and viewport handling
* Procedural map generation
* Tile-based world representation
* Modular rendering architecture
* C++ object-oriented design


## Overview

The project began as the foundation for an isometric RPG and evolved into a standalone projection and rendering engine. While the complete game layer was not finished, the underlying systems for representing, generating, projecting, and rendering an isometric world were developed independently.

The project focuses on understanding the mathematics and software architecture behind isometric environments rather than relying on an existing game engine.
